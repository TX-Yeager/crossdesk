# CrossDesk 跨屏

让连接在 Windows 的鼠标、连接在 Mac 的触摸板和两边键盘，通过同一局域网双向控制另一台电脑，并共享文本、图片和文件剪贴板。两台电脑仍各自运行自己的系统，屏幕保留原来的接线。无需订阅或云服务。

**当前版本是 0.2.10-rc1 开发预览版。Windows 与 macOS 的双向跨屏已有真机验证，但偶发跨屏与光标显示问题仍在排查，不能视为稳定版。Mac 的辅助功能与输入监控需用户本机授权。**

## 安装包与权限

新电脑优先使用 Windows Setup 或 macOS Apple Silicon DMG。[完整安装与权限说明](installer/INSTALL.html)随安装包提供。Windows 安装向导默认配置 CrossDesk 的防火墙规则，只需一次管理员确认；规则限定专用网络、同一子网的 TCP 48193 和 UDP 48194。取消授权后可从开始菜单运行“修复局域网连接”。Mac 需手动开启辅助功能、输入监控，并允许出现的本地网络请求。

安装包属于预览版本，尚无 Windows 商业代码签名和 Apple Developer ID 公证，首次打开可能显示系统提示。仅构建验证 Windows x64 与 Mac Apple Silicon / arm64，未验证 Intel Mac。已有安装优先使用签名功能更新包，保留固定入口和权限身份。

## 开始使用

1. 两台电脑连接同一可信局域网，先在两边启动 CrossDesk。Windows 打包版运行 `dist/CrossDesk/CrossDesk.exe`，整个目录和 `_internal` 必须一起保留。源码版双击 `Start-Windows.cmd`。
2. Mac 源码版运行 `Start-Mac.command`。首次若不能双击，在终端进入项目目录执行 `bash Start-Mac.command`。缺 Python 或 tkinter 时，按提示安装 [python.org 官方 Python](https://www.python.org/downloads/macos/)；启动脚本只在本文件夹 `.venv` 安装依赖，不使用 sudo、Homebrew，也不修改系统 Python。
3. 任选一台创建连接，另一台从局域网发现列表找到它，再粘贴创建端的完整配对码连接。自动发现只显示电脑身份，不替代配对认证。两台都需要完整应用；“创建”和“连接”仅是网络角色，两边均可发送鼠标、触摸板与键盘操作。
4. Mac 点击“Mac 输入权限”，在“系统设置 → 隐私与安全性”按提示允许 **CrossDesk** 的**辅助功能**与**输入监控**。源码运行可能显示 Python 或启动它的终端；打包后是 CrossDesk。授权后重新打开应用，再检查权限。[Apple 输入监控说明](https://support.apple.com/guide/mac-help/mchl4cedafb6/mac)
5. 连接后，先保持暂停，在布局画布中像 macOS 显示器设置一样拖动每块屏幕，使位置与桌面摆放一致。把需要跨越的边缘接在一起；显示器按电脑归属显示，MacBook 内屏与其外接屏分别排列。布局调整后按界面提示保存或应用。
6. **在任意一台点击“开始互控”，两台会一起启用。** 鼠标或触摸板把光标推过相邻屏幕边缘，即可进入另一台电脑。两边键盘跟随当前活动光标所在的电脑，按键本身不会把光标抢回；换用另一边的鼠标移动或点击可以重新接管。界面会显示键盘当前目标。任意一端暂停会同步暂停两端，启动失败则显示原因并恢复本机输入。

“转换常用 Windows / Mac 快捷键”会按组合键转换复制、剪切、粘贴、全选、撤销、重做、保存、查找，以及常用浏览器、应用切换和文字导航操作；未列入的组合保留原样。可在暂停时关闭转换。切屏、松键、断线时会释放旧目标的按键，避免修饰键一直按住。

**随时按 F12 返回本机并同步暂停两端。** Mac 顶行若作为媒体键，可能需要 `fn + F12`。暂停、退出或连接断开时会释放远端按键与鼠标按钮；重连后需手动重新启用。按住鼠标按钮时不跨机，避免跨边缘拖拽造成误点。

本机光标移动交给系统原生处理，跨到另一台电脑后才接管移动。同一台电脑的屏幕之间沿用系统的显示器排列；画布用于安排两台电脑屏幕之间的跨机通道。

Mac 触摸板控制 Windows 时，CrossDesk 使用独立透明窗口管理 Mac 侧光标，主窗口保持可见，不再随着跨屏隐藏。返回 Mac、暂停、断线或退出时会恢复光标；若焦点仍属于 CrossDesk，也会恢复先前的应用。手动切换应用后会尊重你的选择。光标交接独立于较慢的设置界面刷新，不等待剪贴板传输。

互控开启后，按统一的活动电脑显示一个光标，其他电脑隐藏各自的本机光标，包括没有主动发出跨屏移动的空闲电脑。Windows 使用本应用的无激活辅助窗口，不替换系统光标主题；离屏前先隐藏光标，返回时等边缘位置实际生效后再显示，避免露出内部暂存的屏幕中央位置。点击前恢复，避免辅助窗口拦住首个点击。暂停、断线或退出后，两台都恢复各自光标。

Windows 滚轮控制 Mac 时，保持原方向，将滚轮刻度转换为平滑的小步滚动；像素与行字段保持一致，切屏、暂停或输入归属改变后取消旧屏幕上的剩余滚动。Mac 触摸板本身的连续滚动保留其细粒度输入。

Mac 触摸板控制 Windows 时，三指/四指纵向扫动切换 Windows 任务视图，多指收拢/展开切换 Windows 开始菜单。完整手势只触发一次，取消时不执行；对应 Mac 系统动作被拦截，光标继续留在 Windows。相反方向执行同一个切换命令，可再次关闭对应界面。光标在 Mac、互控暂停或对端不支持时，本机手势保留原行为。macOS 15 的系统手势适配使用未公开定义的 Dock 事件字段，后续 macOS 版本需要重新核对，不能视作通用多点触控驱动。

Mac 系统临时显示光标或改变前台时，不再直接暂停互控或把远端光标抢回本机；显示恢复保持有限、配平的隐藏尝试。Windows 切屏的单次定位使用同步物理坐标接口，丢弃交接期间的旧坐标样本；不依赖同像素定位产生额外原生回调。普通连续远端移动保留原来的 SendInput 路径。

设备、偏好与更新分为三个标签；按钮采用简洁圆角样式，滚动条不再带上下箭头。拖动显示器时实时磁吸，实际相接的不同电脑屏幕边缘会显示绿色连接条；有空隙、只接触角点或布局重叠时不会显示可跨屏标记。连接条表示布局通道，加密配对和开始互控仍需按连接状态提示完成。

## 复制粘贴

两边都勾选“共享文本、图片和文件剪贴板”，并开始互控后，可以在一台复制、另一台粘贴。支持 Unicode 文本、剪贴板图片，以及在资源管理器或 Finder 复制的普通文件。无需先切换键盘；常用复制粘贴组合会转换成目标系统的按键。

- 文本上限为 1 MiB；图片按 PNG 传输，最多 1600 万像素、16 MiB。富文本只共享其中的普通文本。
- 一次最多 64 个普通文件，单个 256 MiB，合计 1 GiB。文件夹和符号链接暂不传输，文件夹可以先压缩成文件。
- 文件经当前已配对的 TLS 连接分块传输，逐块确认，不堆满鼠标键盘队列。完成校验后才放入接收端剪贴板；较大文件需要等传输完成。若本次粘贴等待超时，可以在“文件已同步”后再次粘贴。
- 接收文件保存在用户配置目录的 `received-files` 新建子目录中，不覆盖已有文件，不删除原电脑文件。暂停、断线或任意一边关闭剪贴板共享后停止同步；不会把剪贴板上传到云端或写入诊断日志。

## 应用内升级

安装固定入口版本后，点击“从更新包升级…”，选择本项目发布的 `.crossdesk-update` 文件。程序会先验证发布签名、版本兼容性和文件校验，再暂停互控、保留配置并重新打开。遇到问题可用“恢复上一个版本”；未能正常启动的更新会在下次打开时回退。

普通功能更新只更新用户配置目录中的签名代码包，保留现有 `CrossDesk.app`（通常在 `/Applications`）、可执行文件和输入权限所属的程序身份。首次迁移到这个固定入口仍可能需要重新授权一次；以后升级功能代码不再反复重建程序本体。更换入口、原生依赖或系统权限规则变化时仍可能需要授权，不能承诺系统永远不再提示。Apple 的临时签名身份会随具体代码变化，单纯替换安装包无法解决这一点。[Apple 代码签名说明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)

## 网络与配对

- 输入连接默认使用 **TCP 48193**，TLS 加密；可在界面改监听端口，重新生成配对码。局域网自动发现使用 **UDP 48194**，发现失败时仍可直接粘贴配对码。
- 配对码包含创建端 IP、端口、证书 SHA-256 指纹和 256 位随机密钥。它允许控制电脑，请仅在自己的两台电脑间传递。自动发现不会广播密钥。
- 首次出现系统网络访问提示时，只允许自己的可信局域网。Windows 安装向导经管理员确认后添加仅限本应用的局域网规则；不会关闭防火墙、增加端口转发或自动更改网络信任类型。访客 Wi-Fi、AP 隔离、VPN 路由或公司策略可能阻止互连。
- 当前只支持**一对一双机**；已连接的电脑不会被后来的连接抢占。每端可有多个显示器，布局画布独立保存排列，显示器原有的系统坐标与接线不变。屏幕之间有空隙时光标会被阻挡，需要跨屏的边缘应相接。
- 默认状态保存在 Windows `%LOCALAPPDATA%\CrossDesk`，Mac `~/Library/Application Support/CrossDesk`。证书、配对密钥与布局留在各自用户目录；源码可用 `python runtime_host.py --state-dir 路径` 指定独立测试状态。不要把状态目录放在公开共享文件夹。
- 成功配对会在私有 `network.json` 中记住连接，下次打开应用时自动重连。它不会自动启用输入，也不会设置系统开机启动。点击“断开连接”会清除此连接记录；普通退出会保留记录。

## 当前边界

支持普通桌面的光标、点击、滚动、键盘、上述两类手势命令和剪贴板类型。手势映射为 Windows 命令，不能完整传递触摸点或作为 Windows 精确触摸板。当前没有屏幕投送、文件夹持续同步或开机自启。

Windows 的 UAC 安全桌面、锁屏和高权限应用可能拒绝普通权限输入；Mac 锁屏、安全输入、权限不足或系统保留快捷键也可能阻止捕获或注入。请通过本机设备操作这些界面。程序不会为此自动提权或绕过系统权限。

## 开发与构建

当前版本为 0.2.10-rc1，需要 Python 3.10+、tkinter，以及 `requirements.txt` 中的 `cryptography>=44,<51` 和 `Pillow>=12,<14`。GUI 使用标准库 Tk，系统输入通过 Windows API / macOS Quartz 调用，Pillow 负责图片剪贴板编解码。建议每个平台独立创建虚拟环境。Windows 与 Mac 的 `.venv` 不能互相复制使用。

0.2.9 调整跨屏停止逻辑：源光标隐藏失败只显示提示，继续路由输入；真正的捕获、定位、光标窗口清理或本地焦点恢复失败仍暂停并释放输入。停止原因由引擎记录、同步到另一端并保留到下次开始，不再由界面猜测提示文字。相同布局的新版本消息不再暂停，重复开始不重置当前路由，旧确认不能恢复已暂停的会话。清理旧 Mac 主窗口隐藏策略、无入口的接管分支和 Windows 同步隐藏等待。仍保留 F12、双方确认、输入代次、真实定位校验与流光动效。0.2.10-rc1 补充交接诊断，尚未确认所有偶发问题均已解决。

0.2.8 新增“跨屏流光动效”：鼠标跨电脑时，离开端的青紫光粒向屏幕边缘收束，到达端的柔光涟漪展开。原生透明窗口不接收点击、不改变焦点；同一台电脑内移动不播放。可在“偏好”关闭，或暂停互控后点击“预览跨屏动效”。预览仅在本机模拟离开与到达，不实际切换输入。暂停、断线、关闭或快速反向切换时会清理旧动画。客户端打开后仍需点击“开始互控”，任意一端开始会同时启用双端。

```powershell
# Windows，已有本项目 .venv 时
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe runtime_host.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
powershell -NoProfile -File scripts\build_windows.ps1
```

Windows 构建脚本只使用本项目 `.venv`，生成 `dist/v<版本>/CrossDesk/CrossDesk.exe`，不覆盖正在运行的安装。如依赖已安装，可加 `-SkipInstall`；未创建环境时也可用 `-Python C:\路径\python.exe` 指定含 tkinter 的解释器。

两平台启动脚本都会检查 cryptography 和 Pillow，缺失或版本不符时仅更新本项目 `.venv`。正常启动经 `runtime_host.py` 验证并选择业务代码；`python -m crossdesk` 仅供直接运行源码基线，不加载已安装的功能更新。安装后的 `CrossDesk` 命令同样通过固定宿主入口启动。

```bash
# Mac，先用启动脚本准备本项目 .venv
bash Start-Mac.command
.venv/bin/python3 -m unittest discover -s tests -v
bash scripts/build_macos.sh
```

Mac 构建在 Mac 本机生成 `dist/v<版本>/CrossDesk.app`；构建架构跟随本机 Python，不宣称已生成通用二进制。固定入口是根目录 `runtime_host.py` 与 `trustedhost.py`，打包时显式收集业务模块和图片编解码依赖。PyInstaller 必须分别在 Windows 和 Mac 构建，不能在 Windows 直接产出可运行的 Mac 应用。[PyInstaller 官方构建说明](https://pyinstaller.org/en/stable/usage.html)

每次发布必须同时提供 Windows 完整 ZIP、macOS Apple Silicon 完整 ZIP 与 DMG、签名更新包、源码包与 SHA256 校验文件，统一保存在 `dist/releases/<版本>/`。完整包用于新安装；已安装用户优先导入签名更新包，保留固定程序与输入权限身份。不得仅更新功能包而遗漏两端完整安装包。

`scripts/package_update.py` 只把 `crossdesk/**/*.py` 组成签名功能更新包，不能替换固定入口或原生依赖。发布私钥仅在忽略的 `.local` 内，不能上传到另一台电脑或进入分发包。固定入口每次启动会先验证签名并从已验证的内存代码加载业务模块。

测试使用 loopback 临时端口、假输入后端或平台静态检查，不应在开发测试中占用已有服务端口、注入真实键鼠或启动永久监听。项目与衣序部署、Docker、WSL、GPU 无依赖。

`crossdesk/transport.py` 负责 TLS、指纹固定、HMAC 双向认证、心跳和有界队列；`engine.py` 负责输入归属及状态切换；`geometry.py` 负责屏幕布局；`backends/` 是平台输入适配；`discovery.py` 仅广播局域网发现。输入事件和配对码不记录到日志。

用户私有配置目录的 `status.json` 仅保存连接、开关、权限、捕获是否运行等诊断状态；不保存按键名、输入内容、鼠标坐标或配对凭据，也不开放网络诊断接口。

异常与互控退出原因自动写入同一配置目录下的 `logs/crossdesk.jsonl`，可在“更新 → 打开日志文件夹”查看。日志按 1 MiB 轮转，保留当前文件及 3 个历史文件。记录手动暂停、F12、对端暂停、断线、程序退出、更新、定位错误和异常的代码堆栈位置；手势只记任务视图/开始菜单命令。不会记录按键内容、连续鼠标轨迹、鼠标位置、剪贴板内容或配对密钥。定位失败可记录距离目标的绝对误差与错误码，用来区分系统限制范围和定位失败。日志只保留在各自电脑，不自动上传。

**`.local/` 含私有 SSH 测试资料，必须保留在本机，不得提交、压缩分享或加入打包数据。** 构建脚本只收集入口与导入模块，并检查产物中没有 `.local`、配对私钥或密钥文件。仅分发经过校验的发布产物，不要分发整个源码工作目录。

仓库保留源码、测试与构建/安装脚本。`dist/`、本机环境、报告、配对配置和机器专用 SSH 脚本不进入 Git；完整安装包放在 GitHub Releases。发布签名私钥不随仓库提供，其他开发者构建自有签名更新时必须使用自己的密钥与对应宿主公钥。
