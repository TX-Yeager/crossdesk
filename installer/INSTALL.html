CROSSDESK / 安装指南 / 2026.10.28

两台电脑，各装一次。
Windows 网络权限由安装向导配置。

Windows 安装包默认自动配置防火墙，只需确认一次管理员授权。Mac 的辅助功能、输入监控权限由你在系统设置中开启。

版本：0.2.10-rc1 预览版。本次补充安装向导，应用核心与已有发布包相同。安装流程通过验证，不代表此前偶发跨屏问题已经彻底解决。已有安装请优先使用签名更新包，避免替换宿主、重新授权。

Windows · x64

  1. 运行 CrossDesk-0.2.10-rc1-Windows-x64-Setup.exe，按向导安装。
  2. 保留“自动配置 CrossDesk 的局域网连接”的勾选，在 Windows 管理员确认中选择“是”。标准账户可能需要管理员密码。
  3. 从桌面或开始菜单打开 CrossDesk。取消授权也能完成文件安装，但需要稍后在开始菜单运行“修复局域网连接”。

安装到当前用户目录，带卸载入口，不添加开机自启；日常使用无需管理员权限。此预览安装包尚无商业代码签名，Windows 可能显示未识别发布者提示。请核对来源与 SHA256，不要关闭系统防护。

Mac · Apple 芯片

  1. 打开 CrossDesk-macOS-arm64.dmg，将 CrossDesk 拖到 Applications（应用程序）。
  2. 从“应用程序”打开 CrossDesk，再进入系统设置 → 隐私与安全性，分别在辅助功能、输入监控中允许 CrossDesk。
  3. 完全退出并重新打开 CrossDesk。如弹出“本地网络”或网络传入连接请求，允许 CrossDesk。

先安装到固定位置，再授权；不要直接从 DMG 内运行。只构建验证了 Apple Silicon / arm64，未验证 Intel Mac。当前包使用临时签名，未做 Apple Developer ID 公证；首次打开可能需要按系统“隐私与安全性”的说明确认“仍要打开”。不要关闭 Gatekeeper 或 SIP。

首次连接

  1. 两台电脑连接同一个可信家庭或办公室局域网，并打开 CrossDesk。
  2. 按应用内的设备发现与配对码流程连接，核对目标设备。
  3. 在布局中将两台电脑的屏幕摆成实际相邻的位置，再开始共享。
  4. 将鼠标移到相邻边缘即可跨屏。按 F12 停止共享；Mac 键盘设置不同，可能需要 fn + F12。

网络配置后仍连不上

  • 当前网络是“公用”：只有确认是可信网络时，才在 Windows“设置 → 网络和 Internet → 当前连接的属性”中改为“专用”。安装器不会替你判断一个网络是否可信。
  • 取消过管理员确认：从开始菜单打开“CrossDesk → 修复局域网连接”，完成授权。配置结果会明确提示；详细失败信息（如有）在安装目录 firewall-result.txt。
  • 公司策略或安全软件拦截：请管理员按本页规则放行。安装器不会覆盖公司组策略或第三方防火墙。
  • 改过监听端口 / 跨子网 / 访客 Wi‑Fi：默认规则只覆盖 TCP 48193、UDP 48194 和同一子网。自定义端口需同步调整规则；访客网络的设备隔离也可能阻止互连。

更新与卸载

已有安装使用同版本发布目录中的 .crossdesk-update 签名功能包升级。新安装器不会覆盖非空目录，也不会自动重装当前运行的 CrossDesk。

Windows 从“设置 → 应用 → 已安装的应用”卸载。请先退出 CrossDesk；移除本安装创建的防火墙规则时会请求管理员确认。取消时卸载会停止，方便重新授权后完整清理。用户配置与配对记录保留在 %LOCALAPPDATA%\CrossDesk，其他应用的规则不受影响。

Mac 退出应用后可从“应用程序”移除 CrossDesk。隐私设置中的授权可在系统设置中撤销。不要为重装清空系统隐私数据库。
